# "一夜持股法" 模拟观测平台 — 原型设计

日期：2026-07-24

## 背景与目标

用户希望验证"一夜持股法"这一超短线交易策略是否值得实盘采用。原型是一个**模拟盘观测平台**：不接入真实股票数据、不接入真实交易、不接入 LLM，纯粹用虚构数据演示"选股 → 买入 → 次日检查 → 卖出 → 记录 → 循环"的完整流程，并通过资金曲线和历史记录观察策略在不同参数下的表现趋势。

## 一夜持股法 策略规则（本原型建模依据）

- **买入窗口**：每日 14:30 后开始选股，14:45–14:55 尾盘买入
- **卖出窗口**：次日 9:30–10:00，10:00 前必须清仓（一字缩量涨停可延后）
- **选股八项条件**：
  1. 当日涨幅 3%~5%
  2. 量比 > 1.4
  3. 流通市值 50~200 亿
  4. 成交量呈台阶式放量（非脉冲爆量）
  5. 20 日内有过涨停
  6. 全天股价在均价线上方，站稳 5 日/10 日线
  7. 换手率 5%~10%
  8. 属于当日市场前三大热点板块
- **仓位规则（原始策略）**：总仓位 ≤50%，单票 ≤20%，最多同时持 2 只，不补仓不加仓。**本原型默认调整**：因核心需求是"每天推荐3只并全部买入"，"最大持股数"默认值改为 3（3只推荐全部买入），但该值在设置面板中可调回 2 或 1，调小后系统按匹配度得分只买入分数最高的对应数量，其余标记为"推荐但未买入（仓位限制）"
- **卖出纪律**：高开 2%~5% 冲高分批止盈；平开在成本附近离场；低开 <-1.5% 开盘立刻止损；10:00 强制清仓

## 技术架构

单文件自包含 HTML Artifact，原生 JavaScript（不依赖 React/外部库/CDN）。

模块分层（同一文件内逻辑分层）：
1. **State**：资金、当前模拟天数、持仓、历史交易记录、策略参数配置。每次变更写入 `localStorage`，刷新/关闭页面后可恢复进度；提供"重置模拟"清空。
2. **Simulation Engine**：选股算法、买入价生成、次日走势与卖出结果判定。
3. **UI Render**：根据 State 渲染各面板。
4. **Controller**：处理按钮点击（选股/买入、次日检查/卖出、保存设置、重置）。

图表（资金曲线）用内联 SVG 手写渲染，不依赖图表库。

## 模拟引擎细节

### 虚构股票池
预置约 30–40 只虚构股票（虚构代码与名称，明确非真实标的），分布在多个行业（新能源、半导体、医药、消费、军工等），每只有基础市值与波动性属性。每次触发"14:30 选股"时，为股票池内每只股票随机生成当日的：涨幅、量比、换手率、20日内是否涨停过、是否站稳均价线/5日/10日线、成交量形态、是否属于当日热点板块前三。

### 选股算法
用策略设置中配置的阈值，对股票池做筛选打分：
- 硬性条件（涨幅区间、量比、市值区间、换手率）作为过滤条件
- 软性条件（股性、K线形态、成交量形态、热点板块）作为加分项，汇总为"匹配度得分"
- 取得分最高的 3 只，且尽量分布在不同行业
- 为每只生成推荐理由文案（列出命中的具体条件与数值，例如"涨幅4.2%（符合3–5%区间）、量比1.8（>1.4达标）、市值128亿（中盘）、换手率7.3%，属于今日热点板块'半导体'前三"）

### 买入价位
基于模拟出的"当日收盘价"，给出建议买入区间（收盘价 × 0.995~1.005），模拟尾盘 14:45–14:55 的实际成交区间。

### 次日走势与卖出判定
次日开盘涨跌幅按正态分布随机生成，**均值随选股匹配度得分正向偏移**——匹配度越高，次日盈利概率越高。这样调整策略参数（越贴近/偏离标准八项条件）会在胜率和资金曲线上产生可观察的差异，观测平台才有意义（而非纯噪音）。

简化为单步判定（不做盘中分钟级模拟）：按次日开盘涨跌幅 + 卖出规则（高开2–5%视为止盈 / 平开视为离场 / 低开<-1.5%视为止损 / 其余情况视为10点强制清仓）一次性算出卖出价与盈亏——原规则中的"分批止盈"在本原型中简化为按开盘涨跌幅一次性全部卖出，不拆分批次。

## 界面设计

单页 Dashboard 布局：

1. **顶部状态栏**：当前总资金、累计盈亏（金额+百分比）、当前模拟天数、当前阶段（待选股 / 持仓中 / 待卖出检查）。
2. **主操作面板**（随阶段切换）：
   - 「14:30 选股」阶段：点击触发选股算法，展示 3 张推荐卡片（股票名/行业/建议买入价区间/匹配度得分/推荐理由），确认后进入持仓。
   - 「持仓中」阶段：展示当前持仓（买入价、数量、占用资金），按钮"推进到次日检查"。
   - 「次日检查」阶段：展示每只股票次日开盘涨跌幅、触发的卖出规则、卖出价、盈亏，确认卖出后记录，天数 +1，回到「选股」阶段。
3. **资金曲线图**：SVG 折线图，横轴模拟天数，纵轴总资产。
4. **历史交易记录表**：按天列出：日期(第N天)、3只股票及行业、买入价、卖出价、盈亏、当日胜率(3只中赚了几只)。
5. **策略设置面板**：
   - 初始资金输入框
   - 八项选股条件阈值（滑块/输入框，全部可调）
   - 仓位规则（单票上限%、总仓上限%、最大持股数）
   - 止盈止损参数
   - "重置模拟"按钮（清空历史、按当前设置从第1天重新开始、资金恢复初始值）

## 数据持久化

使用浏览器 `localStorage` 保存：资金、天数、持仓、历史记录、策略参数配置。刷新/重新打开页面后自动恢复进度。"重置模拟"清空存储并重新初始化。

## 明确范围外（本原型不做）

- 不接入任何真实股票行情数据或真实交易接口
- 不接入真实 LLM（推荐理由由规则引擎生成的模板文案构成，非 AI 生成）
- 不做盘中分钟级模拟，只做"次日开盘一次性判定"
- 不做多用户/多账户
